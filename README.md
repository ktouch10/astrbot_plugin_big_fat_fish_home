# 大肥鱼小屋 for AstrBot

在 QQ 私聊查看大肥鱼当前在做什么，或者让它把小屋的实时场景截图发给你。

## 安装

1. 下载 [大肥鱼公开版](https://github.com/ktouch10/big-fat-fish/releases/tag/v0.9.0)，按说明启动小屋。默认地址为 `http://127.0.0.1:3218/`。截图需要小屋的浏览器渲染环境，见公开版安装说明。
2. 在同一台机器启动 AstrBot 4.29.4（或兼容的 4.x 版本），接通 OneBot v11 反向 WebSocket，例如 SnowLuma。
3. 在 AstrBot 的「插件 → 安装插件 → 从链接安装」填入 `https://github.com/ktouch10/astrbot_plugin_big_fat_fish_home`。也可下载发行页的 ZIP 手动安装。
4. 打开插件配置。`owner_qq` 填你用来私聊机器人的 QQ 号。启动小屋后从其数据目录的 `qq-link.json` 读取 `port` 和 `token`，分别填进 `home_port` 和 `home_token`。公开便携版默认数据目录是项目根目录下的 `.local/home-data`。令牌只填在本机面板。

## 用法

| 私聊指令 | 效果 |
| --- | --- |
| `/肥鱼小屋` | 读取小屋程序里的当前活动。 |
| `/肥鱼截图` | 捕获发送指令时观察到的场景和状态，肥鱼到手机或电脑前就位后回复。 |

指令仅在配置的主人 QQ 私聊生效。用自定义唤醒前缀时，把 `/` 换成该前缀。插件访问同一网络环境内的 `127.0.0.1`，容器里的 AstrBot 需能通过自身回环网络访问小屋。插件使用 AstrBot 自带的 aiohttp，无需另装 Python 依赖或配置 LLM。

本插件提供小屋状态与截图指令。日记、长期记忆和 QQ 接管由大肥鱼本体按需部署。若同一个 QQ 已由大肥鱼本体处理消息，可用现有的小屋查询功能，避免让两个 QQ 客户端同时回复。
